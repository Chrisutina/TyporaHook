## 2. "转发命令行三件套"结案（2026-09-11）

- 子进程真实 argv（hook 日志）：`["D:\\Typora\\Typora.exe","…\\typora-cdp-test.md"]` —— 干净。
- 主进程收到转发（`typora.log` `got argv`）：`[Typora.exe, --allow-file-access-from-files, --remote-debugging-port=9223, --no-sandbox, <file>]`。
- 来源拆解：
  - `--remote-debugging-port=9223` = hook 的 appendSwitch（v2b 门控后已消失 ✅）
  - `--no-sandbox` = Typora 自身代码 `appendSwitch('no-sandbox')`（hook 日志实锤）
  - `--allow-file-access-from-files` / `--source-shortcut` = Electron/Chromium 单实例转发机制携带
- 结论：**没有外部启动器**；快捷方式、文件关联、右键菜单、计划任务、IFEO、AppCompat 全部检查过，均干净。*（修复见）*
