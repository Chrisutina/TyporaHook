# 常见问题（FAQ）

## 安装 / 部署

### Q1 需要管理员权限吗？
部署到 `Program Files` 下需要（报 `Access denied` 时用管理员运行）；装在 `D:\Typora` 这类自定义目录通常不用。还原、重部署同理。

### Q2 杀毒软件 / SmartScreen 拦截怎么办？
预期摩擦：hook 会写注册表并重打包 `app.asar`，启发式引擎容易误报。加信任或临时放行即可。本工程**不联网**，可自行审计全部源码（5 个 `.ps1` + hook 文件）。

### Q3 会不会动我的 Typora 程序文件？
不会。只替换 `resources\app.asar`（三文件重建版），`Typora.exe`、Electron Fuse、其余文件一律不碰。

## 升级 / 维护

### Q4 Typora 升级后激活没了？
升级会覆盖 `resources`（通常连 `app.asar.bak` 一起冲掉）。重跑 `tools\deploy.cmd`；若 `app.bak\` 也没了，先把 `payload\app.asar.stock-1.14.9.bak` 拷成 `resources\app.asar.bak` 再跑。跑前可先加 `-Check` 看一眼。

### Q5 怎么知道现在是什么状态？
`tools\verify.ps1`（只读）：会给 hook 版本、备份链、注册表、9223 端口逐项打勾并给出结论。

### Q6 还会出现"用久了变未激活"吗？
不会再出现——530s 二次校验定时器已压制（三轮 × 575s 实测）。若哪天又出现，先跑 `verify.ps1`：多半是 Typora 升级覆盖了 hook，重新部署即可。

## 调试 / 排障

### Q7 hook 日志在哪里？
`%TEMP%\Typora_Hook_Log.txt`（即 `C:\Users\<你>\AppData\Local\Temp\Typora_Hook_Log.txt`）。启动成功后会出现 `ok v2b`；插桩会记录 argv / appendSwitch / ≥60s 定时器。

### Q8 怎么开 CDP 调试口？
`set TYPORA_HOOK_DEBUG=1` 后启动 Typora（仅本机 127.0.0.1:9223）。调试完**关掉环境变量再启动**即恢复默认关闭。

### Q9 启动秒退 / 弹 "Error" 框怎么办？
先 `tools\restore.cmd` 回官方（当前 asar 会另存为 `app.asar.hooked.bak`）；若还崩，问题不在 hook。之后用 `deploy.ps1 -Check` 逐步排查。

### Q10 备份链能删吗？
**都别删。** `app.bak\` 不只是备份——它是**运行时读取目标**（hook 会把对 `app.asar\` 的读取重定向到这里），删了 Typora 直接启动失败；`app.asar.bak` 是一键还原的还原源。升级后若被 Typora 覆盖，用 `payload\` 里的素材重建。

## 其他

### Q11 支持哪些 Typora 版本？
实测 1.14.9；1.14.x 理论可用；大版本升级后未验证——升级后先 `verify.ps1`。

### Q12 日志里的 `SLicense restored` 是什么意思？
hook 的注册表轮询（5 秒/次）在保活伪许可证，正常现象。

### Q13 换新机器怎么用？
把 `TyporaHook` 文件夹整个拷过去 → `tools\deploy.cmd` 即可（首次运行自动建备份）。不需要安装任何依赖。
